# Amazon Sales Data Analysis Project

## 📌 Project Overview
This project performs an end-to-end data analysis on Amazon sales transactions to extract actionable insights regarding revenue drivers, product demand, regional sales distribution, and fulfillment efficiency.

## 🛠️ Tech Stack Used
- **Data Cleaning & EDA:** Python (Pandas)
- **Business Intelligence & Dashboarding:** Power BI
- **Calculations:** DAX (Data Analysis Expressions)

## 💡 Key Insights Captured
- **Top Markets:** Maharashtra and Karnataka contribute to the highest volume of total orders and revenue.
- **Product Champions:** Shirts and T-shirts dominate the sales numbers, specifically within sizes M, L, and XL.
- **Fulfillment Trends:** Amazon FBA (Fulfilled by Amazon) handles the majority of the distribution channel, ensuring higher reliability and faster tracking.
